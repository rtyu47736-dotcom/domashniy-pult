# Домашний пульт 💗

Самостоятельный сайт без Tilda и Replit. Статические страницы размещаются на Cloudflare Pages, заявки обрабатываются Pages Functions, история хранится в Cloudflare D1, письма отправляются через Resend.

## Что уже подготовлено
- 7 кнопок просьб: чай, кофе, еда, внимание, открыть/закрыть окно, сладкое.
- Необязательный комментарий.
- Защита от повторной отправки на время запроса.
- Подтверждение отправки; если почта ещё не настроена, сайт честно сообщает об этом.
- Приватная история заявок по паролю.
- Адаптивный дизайн и установка на главный экран телефона (PWA).

## Бесплатная публикация на Cloudflare Pages

1. Создай аккаунт на https://dash.cloudflare.com/
2. Создай GitHub-аккаунт (если его нет) на https://github.com/
3. Создай новый **пустой** GitHub repository, например `domashniy-pult`, и загрузи в него всё содержимое этой папки.
4. В Cloudflare открой **Workers & Pages → Create → Pages → Connect to Git** и выбери репозиторий.
5. Build command оставь пустой. Build output directory укажи `public`.
6. После первого deploy добавь Pages Function files из папки `functions` в корень репозитория (они уже лежат там) и сделай commit/push. Cloudflare Pages Functions автоматически подхватит папку `functions`.

## Подключить базу заявок (D1)

1. В Cloudflare открой **Storage & databases → D1 SQL Database → Create database**, назови `home-remote-db`.
2. Открой базу → Console и выполни SQL из `schema.sql`.
3. В Pages project открой **Settings → Functions → D1 database bindings**.
4. Добавь binding с variable name `DB` и выбери `home-remote-db`.
5. Перезапусти deployment (новый commit или Retry deployment).

## Подключить уведомления на почту

1. Создай аккаунт на https://resend.com/ и получи API key.
2. Для постоянной отправки Resend обычно требует подтвердить собственный домен отправителя в разделе Domains. Адрес получателя уже задан: `cherniqa12@mail.ru`.
3. В Cloudflare Pages project открой **Settings → Variables and Secrets** и добавь:
   - `RESEND_API_KEY` — API key Resend (как Secret).
   - `EMAIL_FROM` — подтверждённый адрес отправителя, например `Домашний пульт <notify@ТВОЙ-ДОМЕН.ru>`.
   - `ADMIN_PASSWORD` — придумай длинный уникальный пароль для страницы истории.
4. После добавления переменных перезапусти deployment.

Важно: нельзя просто подставить произвольный Gmail/Mail.ru адрес в EMAIL_FROM — отправитель должен быть разрешён/подтверждён Resend. Не публикуй API key и пароль в GitHub.

## Проверка

- Открой адрес Pages deployment.
- Нажми кнопку, добавь комментарий и отправь тестовую заявку.
- Если Resend и переменные настроены, появится подтверждение, что письмо отправлено.
- Если почта не настроена, заявка всё равно сохранится в D1, но интерфейс не будет утверждать, что письмо доставлено.
- История: добавь к адресу `/admin.html`, введи `ADMIN_PASSWORD`.

## Важные замечания

- В `functions/api/request.js` и `functions/api/admin.js` находятся серверные функции.
- Письма отправляются через API Resend; API key хранится только в секретах Cloudflare.
- История защищена паролем, но для личного домашнего использования всё равно не публикуй пароль и не пересылай его посторонним.
- Бесплатные лимиты Cloudflare/Resend могут меняться; проверь текущие условия у провайдеров.
